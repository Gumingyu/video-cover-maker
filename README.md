# 谷sir说英语 · 封面生成器

专为中小学英语教育内容创作者设计的视频封面生成工具。
https://gumingyu.github.io/video-cover-maker/

## 功能特点

- **多平台适配** — 小红书、抖音、视频号、B站、微信公众号，一键切换尺寸
- **照片全幅铺满** — 上传照片后可拖动位置、滚轮缩放，灵活调整构图
- **信息流预览** — 模拟小红书信息流环境，判断封面在竞争中够不够抢眼
- **标题预设库** — 内置15个针对中小学家长的爆款标题模板，按场景分类
- **3种视觉风格** — 经典白字、简约黑字、金色醒目，基于点击率数据筛选
- **本地运行** — 纯HTML文件，无需安装，双击用Chrome打开即可使用

## 使用方法

1. 下载 `index.html`
2. 用 **Chrome** 浏览器打开
3. 上传你的照片或视频截帧
4. 填写标题（或从预设库选择）
5. 切换平台，下载对应封面

## 平台封面尺寸

| 平台 | 尺寸 | 比例 |
|------|------|------|
| 小红书 | 1080 × 1620 | 9:16 |
| 抖音 | 1080 × 1920 | 9:16 |
| 视频号 | 1080 × 1260 | 6:7 |
| B站 | 1280 × 720 | 16:9 |
| 微信公众号 | 900 × 383 | 约7:3 |

## 工作流建议

1. 录完视频，截取一帧清晰的人物画面
2. 打开工具，上传截帧
3. 从标题预设库选一个方向，改几个字
4. 切信息流预览，确认封面够抢眼
5. 依次切换平台，下载5张封面
6. 发布
